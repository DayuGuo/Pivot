# 统一搜索入口

按用户明确布局：真实工作区侧栏品牌下移除期刊名称，新增统一搜索框；原“搜索对话”入口并入此处。沿用DESIGN的紧凑低饱和视觉，不增加第二套导航或改变数据库中的期刊名称。

统一检索当前身份可见的对话标题、正式及早期稿件题名／编号、本人内部资料题名。支持大小写不敏感的部分关键词，多关键词同时匹配；百分号、下划线、反斜线按普通字符处理。本轮不做模型语义检索、拼写纠正、正文或作者姓名检索，避免匿名审稿身份和作者未提交草稿通过命中暴露。

GET `/api/search`独立只读模块：请求长度≤160，每类默认8、最多20项，SQL先授权和匹配再限制，不从最近200条工作列表过滤，不返回不可读内容的统计。正式稿件匹配与展示使用当前角色有权读取的题名版本；审稿人只能匹配本人最近邀请的题名快照。私人资料仍属录入者。读取结束复核原会话，搜索不调用模型、不发送邮件、不生成业务修改或批准。

共享原生输入框与非模态结果浮层：防抖、取消旧请求、过期结果隔离、错误显式重试、空结果、键盘与窄屏；修改关键词立即清旧结果。身份变化和401／403清除旧结果。结果使用受限本地链接，沿用原页面的未保存保护；主工作台切换自己的对话保留原草稿，早期稿件可直接定位并刷新恢复。内部资料页原题名过滤与新框联动，其余页面业务筛选保留。

实际测试与截图见PROGRESS；新功能不能借spec029旧测试结论声明通过。主应用／VPS／公开静态演示站不自动更新，原有数据、模型环境、邮件禁发与负责人确认不变。
