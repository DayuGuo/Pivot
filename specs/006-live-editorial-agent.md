# Real-model editorial conversation

Continue spec005's persistent conversation. The existing `/` synthetic intake command stays Mock; `/workbench` gains an explicitly selected DeepSeek adapter (`deepseek-flash`) with real multi-turn tool-call/result messages. Default remains Mock; opt-in without fresh environment credentials returns an actionable unavailable state, never silently falls back. No global Codex configuration changes.

The server constructs role/journal/current manuscript/version/queue context from the authenticated actor and authorized synthetic dataset, plus bounded same-user, same-context history. Manuscript prose, chat history and tool results are untrusted data. No cookies, keys, other users' drafts or unrestricted database records enter the prompt. Only synthetic manuscripts are enabled in this slice; no confidential uploads.

Bounded agent loop: at most 3 provider calls, 8 tool calls, 1 draft mutation. Strict DTOs and server scope checks for every tool. Allowlist: inspect manuscript (summary/text/issues/reviewers), list scoped tasks, navigate materials, prepare a private invitation from human-selected synthetic recipients, open neutral decision review, structured response with server-issued citation IDs. No arbitrary network, SQL, Python, shell, sending, approval, final decision, role mutation or workflow transition tool. Tool execution and receipts are audited; tokens/duration recorded, unknown cost remains null.

Draft preparation is staged until the provider loop finishes successfully. Then apply under the existing actor/case lock, re-read fresh state, preserve human content and authoritative recipients, and commit chat/receipt/draft/audit together. Timeout, malformed/unknown calls, forged citations or exhausted budgets roll back. Same request ID replays the committed response and never calls provider again. A failed provider operation may incur API charge but makes no local business changes; retrying a failed request can call provider again.

Display live versus Mock accurately per persisted reply, independent of current configuration. Model free text is advisory; separate deterministic tool receipts are authoritative. Nothing in natural language grants approval. A responsible human must review private drafts using existing material pages; formal approval/send/decision actions remain unavailable. Never claim a real supplier call succeeded without actually running it using a fresh key.

Acceptance: existing full verification plus provider HTTP contract/error tests; real PostgreSQL tests for context/role/scope, actual tool result roundtrip, evidence provenance, generated draft persistence, idempotency, malicious calls and rollback, model failure/configuration, bounded history and telemetry privacy. Browser tests for provider status/error UI and retained conversation/material actions. Live smoke script performs a read-only synthetic case question and requires provider=deepseek with at least one successful real tool receipt; records no secret or full prompt. If fresh credentials are unavailable, record that blocker and keep the path runnable.
