# spec035：资料区交互与界面精简

2026-11-17。依赖 spec034；本批以单刊编辑试用的资料区为主要改动面。用户要求回顾项目、优化交互与简洁性，继续遵守 Hermes 工作台视觉及 conversation-first 布局。

## 问题与取舍

- 手机顶栏重复占行、输入区偏高，缩减布局高度和空态说明，让正文和对话获得空间。
- 没有全文时优先提供导入动作；已有全文时才推荐方法审阅。保留模型来源、版本、未保存提示和人类确认边界。
- 移动资料抽屉打开后隔离背景，提供焦点约束、Escape、遮罩关闭；设置窗口接管焦点，宽屏恢复普通侧栏。
- 资料对话统一 Enter 发送、Shift+Enter 换行；IME 合成/229 不提交。后端权限和提交幂等机制不变。
- 等待回复时上翻历史，不强制滚到底；以“查看最新消息”由用户选择返回。
- 取消更换原文同时清除浏览器原生文件选择器，允许重新选择同一文件；仍需保存新版本和独立核对。

抽屉行为放入无业务权限的 use-drawer hook，不重写路由、事务或其他工作区。右侧字段/导出/确认保持可访问；不为视觉精简隐藏必要事实。没有新数据库字段、迁移或依赖。

## 验收

四项新增 Playwright 场景覆盖三个浏览器：抽屉焦点和设置交接；输入法/回车；延迟回复保持阅读位置；取消重选文件及持久化。前三项中滚动延迟使用明确合成 UI 响应，其余记录使用隔离 Mock 的真实 API/PostgreSQL。IME 为自动事件覆盖，不是物理输入法认证。
