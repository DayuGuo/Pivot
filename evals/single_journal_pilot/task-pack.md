# 编辑首次试用包

本包只做任务A：两篇公开许可材料、四个开发集问题，覆盖原生Word与出版者PDF、作者关联与正文理解。约30分钟的安排用于熟悉和发现阻断，不是节时实验；没有填写任何人评结果。完整逐点回复仍为0，任务B不在这个入门包中。

在仓库根目录执行：

```bash
.venv/bin/python -m evals.single_journal_pilot.task_pack --output artifacts/editor-first-session-001
```

输出目录必须是仓库`artifacts/`下尚不存在的新目录。已有输出或人工记录绝不覆盖；需要重建时换一个新目录。命令无联网、数据库或模型操作，先复用现有完整语料校验器，再逐字节检查并复制原件。缺少公开原件时先按[材料说明](README.md)取回固定来源，不能拿快照代替原件。本命令没有自动抓取或密钥参数。

分发目录中的全部文件，保留`materials.json`的作者署名、许可证证据、上游链接与版本，不只发两份论文。复制的PDF/Word与上游固定摘要相同，不生成或伪称原生格式。生成物如下：

- `TASKS.md`：给编辑的操作顺序、四个问题及30分钟安排。
- `materials/clinical.docx`、`materials/reproducible.pdf`：固定许可原件。
- `materials.json`：作者署名、来源、许可、版本、字节SHA及无转制说明。
- `editor-record.json`：未执行的空白人工记录，引用位置、语义支持、作者关联、错误及使用意愿待本人填写。
- `timing.csv`：空白计时表，包含等待、失败重试、查证、纠错、导出与中断，不预填0秒。
- `pack.json`、`pack.sha256`：确定性来源绑定与每份文件的SHA；不含生成时刻或机器路径。相同材料/检查点/脚本生成相同字节。

第一次人工填写前，可在包目录运行`sha256sum -c pack.sha256`核对清单本身；`pack.json.files`列出其余文件摘要。人工记录修改后原摘要自然不再匹配，因此保留一份未填写的原始包，复制到个人工作目录填写，并记录原包摘要；不要把修改后记录当成未变的发布包。

两位编辑各领独立副本和本人账号，不分享登录或相互覆盖记录。先阅读原件、独立回答和定位，再看AI输出。选择正确版本逐条核对引用上下文；链接存在不证明每个结论成立。负责人后续安排身份确认和实际评价，不由脚本创建或推断实际参与者。

本包只提供被选中的四个问题，不分发`checkpoints.json`、预选引文、工程参考判断或保留题。论文此前已用于开发；不宣称盲测。包中的编辑任务包含已公开的原文事实，不能把必要的来源内容误当成工程答案。若要严格效率比较，按[评价协议](protocol.md)另行设计匹配材料和顺序；第一次重复看同一原件后的操作时间不能证明提效。
