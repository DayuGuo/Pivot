# 作者投稿与期刊策略补充证据

2026-11-02实际通过Firecrawl读取以下官方页面。正文若未确认再分发许可不在此完整复制；本文件是自己的摘要。官方页面不带稳定版本号，不能冒称每句都属于固定源码release。

## 作者数据与声明

[OJS Authors](https://docs.pkp.sfu.ca/learning-ojs/author/en/)与[Janeway Author guide](https://janeway.systems/pages/support/guides/author-guide)均把投稿整理为多阶段：稿件信息、作者、文件、最终核对，再正式提交。由此采用作者可恢复准备稿+完整审核快照，不让对话一句“提交”直接冻结并送审。

Janeway指南明确标题必填，摘要/语言/许可等要求受期刊配置影响；关键词可为短语，自定义额外字段独立。我们将字段规则置于版本化期刊策略，v0.1提供一个research_article策略，避免模型根据经验自行删必填项。长表单用有界JSONB承载额外内容，标题/摘要/语言/类型/外键仍用关系字段。

作者信息不是Account的同义词：手工添加作者不会自动创建账户，通讯作者也未必排第一。指南说明可通过后续动作链接账号；我们的授权更保守，明确owner/assignment授予，邮箱相同不自动获得稿件访问。署名顺序/机构/ORCID独立快照跟随稿件版本；ORCID/ROR字符串未经过认证时不能标为身份核实。

资助信息包含资助者、资助者标识和项目号；没有资助时可为空，不能为完成表单杜撰。版权、费用和投稿清单是否必需取决于期刊设置。AI可整理文字候选，原创性/版权/利益冲突/伦理适用性等声明必须由人明确填写，不能默勾或因为deadline自动接受。

## 栏目、文件与权限

[OJS Policies](https://docs.pkp.sfu.ca/learning-ojs/journal-managers/en/policies)将栏目、分类、文件组件、审稿规则和许可分开：栏目可设是否外审、摘要要求、限编辑投稿、默认表单；分类服务发现和组织，不是workflow状态。我们的核心“走到哪一步”来自确定性步骤，学科/栏目标签不授予权限或跳关。

Janeway的原稿、图表、数据有不同用途，文件标签与描述不同；OJS也允许配置组件。v0.1文件关联要存purpose/visibility/digest/version和显示名，不能只存路径或把二进制塞进文章JSON。匿名审稿必须对真实文件与文件名分别审查，不能仅隐藏界面作者一栏。

## 初审与生产边界

[Janeway Editor submissions](https://janeway.systems/pages/support/guides/editor-guide-to-submission.html)说明unassigned与已分派处理分开，并允许内部预计期号不等于正式期号公开。我们把当前步骤、责任任务、预计出版信息与最终预览快照分开，不因设期号就对外发布。

该指南允许编辑接受/拒绝或跳过外审并警告作者兼编辑冲突；我们不复制可手工绕过的默认权限，v0.1默认不允许本人审批自己的投稿，正式决定须主编独立确认，邮件内容审批另行进行。所有对外发送继续禁用。

指南部分文字把“accepted”用于进入评审前情景，语义容易混淆；状态枚举与转换以固定版本源码及实际服务测试为准，不把自然语言文档一个词直接当数据库状态设计。
