# 编辑内部审阅资料包（spec013）

2026-11-03，本地增量；公网静态Demo不变。目标是让一本期刊的编辑真正录入、保存并逐版核对材料，先建立可信版本边界，再开发真实模型审阅。

## 已实现范围

`/library`保留左侧资料列表、中心对话与右侧资料/全文/版本，手机可以切换资料面板。编辑在真实登录会话下创建私有资料包，记录标题、独立摘要、语言、关键词、有序作者、贡献、机构、通讯邮箱、可选ORCID及来源。完整UTF-8 TXT/MD不超过1MiB，保留原始字节与SHA256；不能把摘要冒充全文。只用合成或明确授权的公开材料，来源由负责人显式声明。

每次保存追加完整快照，包含作者顺序和文件名/媒体类型；共享内容blob不会覆盖另一版本的文件名。独立核对页面展示该版材料、原文、来源及缺项，负责人重新勾选并确认确切内容digest。新版本不会继承旧核对。旧版本、核对与规则回合由数据库禁止UPDATE/DELETE/TRUNCATE；修改冲突返回409。

角色、期刊、录入者、CSRF和原会话身份在服务端确定性检查，幂等重放同样重新鉴权。主编不自动读取其他编辑的内部材料。审计只写版本/修订引用，完整正文及作者邮箱不写审计details。没有伪造author账户或放宽既有author_draft权限。

## 对话与限制

对话明确标记“规则引导 · 未调用模型”，按当前版缺项、核对状态回答准备步骤并保留数据库回合。它没有科学审阅、联网检索、邮件发送或编辑决定工具。ORCID是手填格式归一，没有OAuth或人物身份认证；不是可信身份结论。资料包不等于正式投稿，当前没有共享、转换投稿、PDF/DOCX解析或正式业务操作。

下一切片才是与确切版本绑定的只读模型问答：可靠定位原文、区分稿件证据与外部来源、检测材料变更后证据失效；外部DOI/ORCID等来源需要逐类实际核验。接入模型前落实数据授权和字段边界。进入真实受控试点前请专业工程师独立复核访问控制、隐私、备份恢复与部署；自动测试不能替代该项复核。
