# spec019 验收记录

本轮处理已安装私人体验版的恢复、分页和单进程资源控制。不连接或更新用户VPS，不修改现有数据库结构、历史回执、邮件权限或人工关口。实施合同见[spec019](../../specs/019-recovery-pagination-and-admission.md)。

## 实际问题与修复

- 修复前两条浏览器回归均失败：已知写成功后GET失败仍重发POST；跨稿件旧请求使新稿件输入一直禁用。现在保留写/读阶段进度，只有未知写结果使用原UUID主动恢复，路由代次和独立操作标识分别隔离旧结果与finally。失败证据spec019-before.log。
- 新回归发现浏览器返回后仍停留在新建表单，以及并行分页撤权后的错误未显示。返回同步失效旧请求、load重置表单，权限拒绝清除私有材料并失效并行回复；登录拒绝退出loading。不是取消已执行的后端事务。
- 网络/429/503/不完整JSON均无自动重试，用户主动重试前验证身份未变。编辑表单撤销旧重试入口。已知写成功的读失败隐藏旧快照；人工核对结果刷新后，版本列表同步更新。
- 资料原来无界列表、消息50条截断且无法向前看、版本无界和导入100条截断。现在四者都有明确加载入口和限定scope的keyset页；搜索覆盖全部本人有权资料，防抖且不丢当前表单。后端Answer/Version/Approval关联仅取本页。
- API/Web在重任务正文之前拒绝超额请求，HTTP429/Retry-After:2，解析与模型共享一个名额；轻读取与人工核对仍受原鉴权但不占重名额。每进程计数，私人包保持单worker，不能直接当作分布式限流。

## 验证范围

先行资料专项135项通过39.80秒；新增分页/并发10项通过2.18秒，首轮测试夹具尝试改created_at被不可变DB guard拒绝，改插入前设定；修复夹具的UTC命名错误后全部通过，未放宽保护。资料浏览器专项14项通过9.2秒，后续补长对话视口回归。完整verify、最终游标类型回归及原生安装/并发实验的最终结果在PROGRESS顶部；本报告不能用待运行项目代替已验证功能。

新安装的四路上传实验由scripts/accept-vps-concurrency.py运行，只读取accept-vps-preview生成的仓库artifacts下pivot-check-* Mock状态；忙请求应有429且无回执，按同UUID顺序恢复/重放后完整资料投影不变，不调用确认/邮件/决定。报告记录后续容器内存峰值和OOM状态，不等于用户VPS整机负载能力。

界面沿用DESIGN.md的Hermes三栏、中心对话和现有字体/配色。[Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)本轮实际读取，UI/UX库检查错误播报/导航/状态；Impeccable机械检测空数组，不替代实际浏览器视觉检查。Uvicorn官方页本轮读取超时，单worker与总并发依据已提交入口及实际容器运行，不把未读取资料当证据。

## 后续全量暴露的问题

1194后端（381.37秒）通过后的浏览器发现空搜索也附加query参数，使既有导入/引用fixture未匹配而真实401。保留空搜索原URL、集中dossierListURL；新分页fixture按pathname匹配两种合法请求，不删除原断言。核对状态新断言原来匹配侧栏许多已核对资料，限定独立核对region。另补保存中改变搜索时旧列表读取不能覆盖新结果的代次检查。最终三组资料/导入/证据29浏览器通过19.6秒。旧候选完整CI已取消、不发布，最终源码从头完整验证。

本机旧数据32表816行摘要在实际API/Web更新前后相同，真实DeepSeek保存5条全文/元数据引用，原UUID重放相同、未确认。3次provider attempt均成功，输入7694/输出478tokens、供应商4978ms，墙钟因驱动断言中断未保存而保留null，费用null。首次驱动错误要求所有引用来自全文，纠正为按text/metadata核对各自原文后恢复同一记录，不重复推理。真实浏览器baseURL修正后，准确高亮/刷新/375px/200%通过，确认/邮件/决定/新增模型请求0。均为本机合成资料，不是VPS或科学审稿认证。

## 限制

分页不是长事务快照，新增或改变搜索匹配的记录须重载首屏。游标不授予权限，SQL/对象校验仍是边界。尚未提供跨刷新未发送表单恢复、多设备未知写请求outbox或多副本共享并发名额；后台任务不能由关闭页面撤销。邮件禁用，关键决定与资料核对继续由有权负责人独立确认，正式保密试点仍须专业复核。
