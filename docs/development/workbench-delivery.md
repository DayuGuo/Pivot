## 运行与演示

`./scripts/start.sh`，编辑/主编在`http://localhost:3100`登录并点击“我的工作”，或进入`/workbench`。公开合成账号：editor@publishing.test / EditorDemo2026!；chief@publishing.test / ChiefDemo2026!。原投稿与邮箱功能保留于`/`。

主案例ENV-2026-0129：工作列表选择→阅读长篇中英文稿→定位某条问题的原文/修回证据→选人/比较并准备邀请→两轮修回核验→中性拟定结果与决定信草稿预览。所有稿件、候选、论文来源、历史和分析均明确合成；只有个人工作区操作记录/草稿/核验是真实保存。

## 明确的模拟部分与待接入接口

- Fixture不是实际科研证据，.test候选/文献均虚构。论文为合成文本，不包含PDF/DOCX上传解析、真实稿件附件存储或病毒扫描。
- AI为受控浏览器模拟任务，非真实供应商推理；刷新会终止未完成模拟计算，已保存结果恢复。没有真实DeepSeek调用。后续以受控任务服务替换此接口，并沿用版本/权限/人工边界。
- 草稿和个人核验不构成正式学术结论；未来规范化版本/轮次/任务/人工确认按spec003接入。禁止将演示JSONB表直接用作全部出版数据库。
- 发送记录为空：没有发信传输器，未生成成功发送事件。EMAIL_SEND_ENABLED=false；逐封快照审批/outbox等正式能力待实施，不因准备邀请/决定草稿而启用。
- 独立审核页中的本轮快照为可核对草稿预览，不是已实施的spec003逐关正式审批。正式发信、决定、任务取消及权限变更仍需未来专用后端关口，当前failclosed。
- 仅实际验证Linux Chromium。Windows/macOS、Firefox/Safari、原生浏览器工具栏200%缩放、OS缩放、读屏器均未实测。自动化放大设置Chromium document CSS zoom=2，实际检查放大后可见/可操作与溢出，不冒称全部平台验证。
