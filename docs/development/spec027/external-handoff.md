# 外部评价与专业复核交接

工程候选已按[结果台账](results.json)验证，以下任务尚未执行。负责人组织输入和人员；本文不代表已经邀请、采购、批准正式业务或安排VPS更新。

## 编辑评价

负责人提供两位获期刊授权的实际编辑、明确可发送给模型的材料范围、完整原稿/修订稿/审稿意见/作者逐点回复及许可。第一位先隐藏AI和工程参考判断建立参考记录，第二位独立复核严重风险项及部分随机题，保留分歧。按[准备包protocol](../../../evals/single_journal_pilot/protocol.md)记录实际分子/分母、不同论文数、净时间、查证纠错时间及继续使用意愿。现有6篇/42项并非未知语料，9项只从冻结时开始保留；不能冒称盲测。

当前私人VPS包是单操作人配置，资料按录入者隔离，没有多人共编或外部评价者身份认证。可在获授权的导出材料上独立评价，再由负责人按既有回传入口核对；不共享账号，不由代号推算真实评价人数。正式多人线上试用另需安排账户和访问边界。

## 六个工程工作包

| 工作包 | 工程师检查入口与证据 | 负责人需提供/完成凭据 |
| --- | --- | --- |
| 文件处理 | `packages/document_ingest`、私有CAS、PDF/Word回归；检查格式/资源限额、失败退出、原件与解析身份 | 获授权攻击样本及独立发现/复查记录；不能把资源限制当OS沙箱 |
| 对象权限 | dossier_access、core.ensure_actor、新核对来源/导出；跨对象/跨刊、换身份、撤权/历史/重试 | 实际账号矩阵与人工冲突场景；职务任期字段和自助账户当前未实现 |
| 版本与确认 | document_imports、revision_sources/reviews、迁移28a7；旧指纹/并发/不可变/未知结果 | 核对当前/历史版本、更换文件和已确认内容的失效规则，不以AI输出作批准 |
| 模型数据流 | model_gateway、document_candidates、claim_support；实际窗口、纠正、超时/协议失败及安全遥测 | 机构认可的模型/材料/保留政策；凭据只走安全环境，不发给审阅人或写普通导出 |

## 设备与放行

负责人安排可用的Windows Edge、macOS/iOS Safari、Android设备，实查原生文件选择、中文候选确认、软键盘、横竖屏、后台返回、断网、切稿、引用和未保存保护，记录设备/版本/日期/失败。Linux三引擎和合成IME事件不替代真机。

真实编辑评价、专业复核、实际支持责任和期刊/出版社授权齐备后，才判断是否承担选定正式流程。25%净节时和两位愿意继续是内部投入目标，不是既得结果或行业标准。邮件保持禁用，正式提交/决定仍由具体负责人核对；部署与合并另按用户明确授权执行。
