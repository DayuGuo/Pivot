# 项目回顾与 UI 交互精简（spec035）

2026-11-17；本轮目标是改善编辑试用中的操作连贯性，不改变出版权限或扩大产品范围。实现基于未合并的 spec034，独立草稿 PR #16。

## 回顾结论

Pivot 已有完整的本地出版纵向样本，以及私人资料录入、PDF/Word 候选提取、逐版本引用、独立人工核对、修回核对和评价回传。身份、对象范围、版本与审批仍由后端确定代码管理。当前更有价值的是让编辑顺畅完成一次审阅，再用实际反馈决定下一步；不是继续堆叠功能入口。

本轮复读产品、架构、安全、决策、进度和模块地图，检查资料对话/编辑器/证据/设置/建议及共享交互实现，并抽查资料角色/归属/版本检查和只读模型工具边界。改动集中在资料区；这不是全仓逐行审计或外部专业安全验收。其他工作区及后端由既有全量回归提供工程覆盖，不能据此推断所有潜在缺陷都已排除。

## 本批修复

| 原问题 | 改动 | 验收依据 |
| --- | --- | --- |
| 手机顶栏和输入区挤占对话 | 标题与必要边界合组、两行输入、缩减空态间距与说明 | 1360×850、390×844 实际截图 |
| 空稿件过早引导全文审阅 | 无全文先显示真实导入入口，有全文才推荐方法问答 | 空态与实际导入流程回归 |
| 手机侧栏无模态焦点管理 | 独立 hook，背景 inert、Tab 循环、Escape/遮罩关闭、设置焦点交接、宽屏恢复 | 三引擎抽屉回归 |
| 资料区回车行为不一致 | Enter 发送、Shift+Enter 换行；IME/229 不发送，保留请求/版本 guard | 三引擎输入事件及持久消息 |
| 新回答打断历史阅读 | 仅接近底部时自动跟随，否则由“查看最新消息”返回 | 明确合成延迟回复 fixture |
| 取消文件后选择器仍显示文件 | 同步清空原生 input，允许重选同一文件 | 新版原文实际持久化 |
| 无效文件令元数据无法保存 | 错误状态也有取消入口，清除错误后保存元数据、沿用原文 | 三引擎真实 API/PostgreSQL 回归 |

保留当前/历史版本、Mock 来源、未保存输入和人类确认标记。删除或隐藏这些事实会误导操作者，不属于“减少次要标签”。右侧表单和导出仍可访问，没有把操作换成无效按钮。

## 模块与后续维护

`use-drawer.ts` 只管理资料侧栏的焦点/视口行为；workspace 继续组合数据与操作，editor 管理表单与文件候选。没有新依赖、表或迁移。继续保留 Action Gateway、对象权限、幂等、epoch 旧请求隔离与不可变版本，不复制后端权限到 UI。

下一轮优先让两位编辑按既有试用包完成真实任务，记录找不到的入口、重复填写、回退次数及净耗时，再判断是否统一主/出版/资料入口。长表单按“必需字段—可选资料—核对”渐进呈现，必须先验证没有隐藏缺项与确认依据。移动端实体键盘、软键盘、屏幕阅读器和实际 Safari 仍需真机测试。真实 DeepSeek 与语义质量、专业权限/文件安全/备份部署复核仍是独立门槛。
