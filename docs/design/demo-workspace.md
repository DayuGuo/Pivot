# 展示 Demo：Oper​ate surface brief

2026-11-03。用户先展示产品思路、再逐步细化。已有 Hermes 截图和 DESIGN.md 是视觉权威；本次为明确指定三栏的局部产品延伸，不更换品牌、不做概念抽签或营销首页。

目的：让期刊中心在五分钟内体验“从我的工作进入稿件，以对话理解材料，点击证据回到来源”。在独立 `/demo` 使用公开链接和原创合成稿件，不调用业务 API、模型或邮箱；浏览器本地存储可重置。静态导出可单独放到低内存 VPS，现有 `/publishing` 保持原有业务边界。

布局：左对齐。桌面左侧约232px放本人待办、稿件会话、底部日历；中间弹性列始终保留主体对话；右侧约360px放稿件进度、原文、作者资料与证据。窄屏中间占满，任务和材料用独立抽屉；不挤成三条窄列。

色彩：画布 #ffffff，侧栏 #f5f7fa，正文 #30343b，次要正文 #646c78，细边 #e3e8f0，交互 #2463ff。继承自托管 Noto Sans SC，正文15–16px/1.8、控件12–14px、小圆角、无卡片阴影与装饰渐变。选中行、页签下划线承担导航层级。

对照用户要求：保留常驻输入框、主对话与稿件会话、明确当前步骤、左下角可点的截止日日历。UI/UX Pro Max搜索推荐的作品集/衬线字体不适合已确定的工作台，因此仅采用其键盘焦点、对比度和响应式知识。没有新增视觉系统，原 DESIGN.md 不改。

验收：会话隔离和刷新恢复、元数据/正文的本地编辑、引用定位真实段落、真实外部文献链接、日历筛选、危险请求不产生动作、窄屏可访问和零业务 API 请求。模拟回答始终标明来源；样例 ORCID 缺失不能伪造认证；导入仅支持真实 TXT/Markdown，不假装解析 PDF。

部署约束：静态资源在本机构建，VPS仅托管；无密钥、数据库、邮件或生产服务。实际公网IP/域名与SSH访问尚未提供，不能声称已经公网部署。机房Test IP不当作用户服务器地址。
