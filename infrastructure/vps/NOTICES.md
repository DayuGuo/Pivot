# Dependency notices

This bundle contains Pivot application code and third-party runtime images. It does not assign a new open-source licence to Pivot or relicense its dependencies. Refer to the project repository for the application's distribution terms.

The Web image retains the installed npm dependency and font licence/notice files under `/app/third-party-notices/`, including Noto Sans SC's SIL Open Font License. `index.json` lists the retained paths. Python wheel metadata/licences remain with installed distributions in the API image. PostgreSQL and the Node/Python/Debian/Alpine base images retain their bundled notices and package metadata. Consult those original licences for their terms; this file is a directory, not a replacement licence.
